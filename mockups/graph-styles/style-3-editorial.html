Editorial

Editorial. Cream canvas, every node a single coloured dot with the type label above and an italic serif name below. Edges are 0.6-px hairlines terminating in a small dot (no arrowheads — the layout direction is enough). Reads like a Financial Times or New York Times network diagram. Best when you want the chart to feel like a published infographic, not a tool. Tradeoff: less obvious where to click; the dropdown / inspect interactions have to be more discoverable.
